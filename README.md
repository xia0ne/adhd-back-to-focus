# 回神 · Back to Focus

> **专为 ADHD 与深度阅读者打造的段落聚焦与注意力回神浏览器插件。**  
> 遵循 Apple 人机交互界面规范（HIG），提供纯净、无 AI 浮夸干扰、无打断愧疚感的阅读与元认知体验。

---

## 核心特性

1. **逐段聚光灯阅读（Paragraph Spotlight）**
   - 提取并聚焦当前阅读单元，柔和暗化上下文，彻底告别机械扫视与行距迷失。
   - 使用 `J` / `K` 或 `↓` / `↑` 丝滑吸附切换，保持视线处于人体工学舒适区。

2. **理解检查点（Comprehension Checkpoint, `C` 键）**
   - 真正读懂核心逻辑后按 `C` 盖印确认。建立工作记忆物理锚点，而不是单纯记录页面滚动条。

3. **一键回神（Snap Back, `R` 键）**
   - 读到第 15 段突然惊醒“从第 8 段开始就走神了”？按下 `R` 键，瞬间从容倒退至最近一次理解检查点，零心理负担重启阅读。

4. **各大主流 AI Web 界面深度适配**
   - 专有 DOM 解构引擎，针对 **ChatGPT、Claude、Gemini、DeepSeek、Kimi** 等对话容器进行优化。
   - 智能折叠思维链（Thinking Block）、列表条目独立聚焦、代码块原子化保护。

5. **双感官语音辅助阅读（TTS Anchor, `S` 键）**
   - 利用系统内置 Web Speech API 原生自然朗读，按 `[` / `]` 调节语速，以视听双通道锁住注意力。

6. **Apple 风格灵动药丸胶囊（HUD）与轻提醒**
   - 极窄半透明磨砂玻璃设计，定时温和询问“思维跟上了吗？”，不阻断阅读心流。

## 快捷键速查

| 按键 | 说明 |
| :---: | :--- |
| **`Alt + F`** | 全局开启 / 退出回神聚焦模式 |
| **`J` / `↓`** | 平滑吸附至下一段 |
| **`K` / `↑`** | 平滑吸附至上一段 |
| **`C`** | 标记理解检查点（我读懂了这里） |
| **`R`** | 一键回神至检查点（倒退跳过走神段落） |
| **`S`** | 开启 / 暂停当前段落语音朗读 |
| **`[` / `]`** | 减速 / 加速语音朗读（0.8x ~ 2.5x） |
| **`Space`** | 处于唤醒提醒时确认“专注中” |
| **`Esc`** | 退出聚焦模式 |

*注：在输入框或聊天框打字时，插件会自动暂停按键捕获，不干扰正常对话输入。*

## 安装使用指南

本扩展基于 Chrome Extension Manifest V3 纯原生开发，**零构建依赖**：

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的 **“开发者模式” (Developer mode)**
3. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**
4. 选择本项目根目录 `ADHD-BackToFocus`
5. 打开任一长篇文章或 AI 对话网页（如 ChatGPT / Claude / DeepSeek），按 `Alt+F` 即可开启回神体验。
